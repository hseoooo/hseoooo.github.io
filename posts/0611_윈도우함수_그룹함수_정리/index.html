그룹 함수 & 윈도우 함수 정리#

대상 DB: chinook.db (SQLite)

1. 윈도우 함수와 그룹 함수의 개념 차이#

구분 그룹 함수 (GROUP BY) 윈도우 함수 (OVER)
행의 수 그룹별로 행이 축소(집계) 됨 원본 행 수가 그대로 유지됨
결과 형태 그룹당 1개 행 각 행마다 집계값이 추가됨
용도 전체를 요약/축약 개별 데이터 + 집계 정보를 동시에 비교
예시 “국가별 평균 구매액 한 줄씩” “각 주문 옆에 그 국가의 평균 구매액 표시”
핵심 키워드 GROUP BY, HAVING OVER(), PARTITION BY, ORDER BY

한 줄 요약: 그룹 함수는 “여러 행 → 한 행으로 압축"하지만, 윈도우 함수는 “각 행은 유지한 채 그 행이 속한 그룹의 통계치를 함께 보여준다.”

같은 AVG, SUM 같은 집계 함수라도 OVER()를 붙이면 행이 줄어들지 않고, 각 행에 계산된 값이 옆으로 붙어 나온다 (문제3의 서브쿼리 방식 vs 윈도우 함수 방식 비교 참고).

2. 윈도우 함수 (Window Function)#

2-1. 순위 함수#

  • RANK(): 동률 시 다음 순위를 건너뜀 (1, 2, 3, 3, 5)
  • DENSE_RANK(): 동률 시 건너뜀 없음 (1, 2, 3, 3, 4)
  • ROW_NUMBER(): 항상 고유한 연속 번호 (1, 2, 3, 4, 5)

활용:

  • 고객별 총 구매액을 기준으로 전체 순위 매기기
  • PARTITION BY를 사용해 국가별로 순위를 따로 매기기 (그룹별 순위)

2-2. 일반 집계 함수 + OVER#

  • AVG(...) OVER (PARTITION BY ...): 그룹별 평균을 각 행에 표시 (서브쿼리로도 동일 결과 가능하지만 윈도우 함수가 더 간결)
  • SUM(...) OVER (): 전체 합계를 모든 행에 동일하게 표시
  • SUM(...) OVER (ORDER BY ... ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW): 누적합계(Running Total)

2-3. 그룹 내 행 순서 함수#

  • FIRST_VALUE() / LAST_VALUE(): 파티션 내 첫 번째/마지막 값
    • LAST_VALUE()는 ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING 명시가 필수 (안 하면 현재 행까지만 봐서 결과가 다르게 나옴)
  • LAG(col, N): N번째 이전 행의 값 (없으면 NULL) → 직전 청구금액
  • LEAD(col, N): N번째 이후 행의 값 (없으면 NULL) → 다음 청구금액
  • 활용: 전월 대비 매출 증감(MoM) 계산 시 LAG()로 전월 값을 가져와 현재 값과 차이 계산

2-4. 그룹 내 비율 함수#

  • RATIO_TO_REPORT: 전체 합계 대비 비율 → SQLite에서는 값 / SUM(값) OVER()로 대체
  • PERCENT_RANK(): 순위 백분율, 범위 [0, 1], 최고 순위 = 0
  • CUME_DIST(): 누적 백분율, 범위 (0, 1], 0 미포함
  • NTILE(N): 데이터를 N등분하여 그룹 번호 부여 (예: 직원을 입사일 기준 3개 그룹으로 분류)

3. 그룹 함수 (Group Function)#

3-1. GROUP BY (기본)#

  • 여러 컬럼으로 그룹화 → 그룹별 집계 (예: 장르 × 미디어타입별 트랙 수, 평균 단가)

3-2. ROLLUP (계층적 소계)#

  • (A, B) 조합 + A별 소계 + 전체 합계, 총 3가지 레벨
  • SQLite는 미지원 → UNION ALL로 각 레벨을 따로 작성해 합침

3-3. CUBE (모든 조합)#

  • (A, B) + A별 소계 + B별 소계 + 전체 합계, 총 4가지 레벨 (ROLLUP보다 한 단계 더 많음 - B별 소계 포함)
  • SQLite는 미지원 → UNION으로 각 조합을 따로 작성해 합침

3-4. GROUPING SETS (원하는 조합만 선택)#

  • 원하는 그룹 조합만 따로 지정 (예: A별 통계, B별 통계만 - 둘의 교차 조합은 없음)
  • SQLite는 미지원 → UNION ALL로 각 그룹별 쿼리를 작성해 합침
그룹 함수 생성 레벨 SQLite 지원 대체 방법
ROLLUP(A, B) (A,B) + (A) + 전체 → 3가지 미지원 UNION ALL
CUBE(A, B) 모든 조합 + 전체 → 4가지 미지원 UNION
GROUPING SETS (A) + (B) → 2가지 미지원 UNION ALL

4. 핵심 정리#

  • 그룹 함수: 데이터를 압축해서 요약 보고서 형태로 만들 때 사용 (행 수 감소)
  • 윈도우 함수: 원본 데이터를 유지하면서 비교/순위/누적/이동평균 등 분석을 추가할 때 사용 (행 수 유지)
  • 실무에서는 “전체 대비 비율”, “그룹 내 순위”, “전월 대비 증감” 같은 분석에 윈도우 함수가 훨씬 강력하고 코드가 간결함
  • SQLite는 ROLLUP/CUBE/GROUPING SETS를 지원하지 않으므로, UNION 계열로 직접 구현해야 함
