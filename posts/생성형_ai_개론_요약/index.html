June 5, 2026

생성형 AI 개론 요약#

1. AI란 무엇인가#

AI(인공지능)는 데이터를 학습하여 인간처럼 생각하고 판단하는 지능적 작업을 수행하는 기술이다.

AI가 하는 일은 크게 네 가지로 나뉜다.

  • 인식: 이미지, 음성 인식 (예: 사진 속 얼굴 인식, 음성 텍스트 변환)
  • 예측: 데이터 기반 미래 예측 (예: 주가 예측, 날씨 예보)
  • 판단: 추천 및 의사결정 지원 (예: 넷플릭스 콘텐츠 추천)
  • 생성: 텍스트, 이미지 생성 (예: ChatGPT, Midjourney)

2. AI 기술의 발전 단계#

시대 기술 핵심 특징
1980s 규칙 기반 AI 사람이 입력한 규칙대로 작업 수행
2000s 머신러닝 데이터로 패턴 학습
2010s 딥러닝 이미지·음성·언어 인식
2020s 생성형 AI 텍스트·이미지·영상 생성

3. 왜 갑자기 AI인가#

AI가 폭발적으로 확산된 데는 세 가지 요인이 맞물린 결과다.

  • 데이터 폭증: 인터넷·스마트폰·IoT 기기의 보급으로 학습에 쓸 수 있는 데이터가 폭발적으로 증가
  • 컴퓨팅 성능 향상: GPU와 클라우드 인프라의 발전으로 대규모 모델 학습이 가능해짐
  • AI 모델 발전: 딥러닝 → 트랜스포머 → LLM으로 이어지는 모델 구조의 혁신

세 가지가 동시에 무르익으면서 AI 혁신이 촉발됐다.

4. 전통적인 AI vs 생성형 AI#

구분 전통적인 AI 생성형 AI
목표 데이터를 학습해 예측에 집중 데이터를 학습해 새로운 콘텐츠 생성에 집중
예시 번호판 이미지를 학습해 차량 번호 인식 이미지를 학습해 새로운 이미지 생성

5. 생성형 AI란?#

텍스트, 이미지와 같은 콘텐츠(미디어)를 생성할 수 있는 인공지능이다.

  • 단순한 정보 전달을 넘어서 텍스트, 이미지, 코드, 오디오 등 다양한 형태의 콘텐츠를 만들어낼 수 있다.
  • 기존의 자동화 기술과 달리 새로운 결과물을 제작하는 것이 핵심이다.

6. 생성형 AI 서비스의 종류#

사용자가 입력한 텍스트(프롬프트)를 기반으로 다양한 콘텐츠를 생성한다.

텍스트 생성형 AI: 사용자의 질문(작업)에 맞춰 답변(텍스트 또는 코드)을 생성

  • 대표 서비스: ChatGPT, Claude, Gemini, Perplexity

이미지 및 영상 생성형 AI: 사용자가 요청한 상황, 객체 설명에 맞춰 이미지를 생성

  • 대표 서비스: Midjourney, Canva, Gemini

오디오 생성형 AI: 타인의 음성 샘플을 이용하여 사용자가 작성한 대사에 맞춰 음성을 생성

  • 대표 서비스: Fish Audio, Suno

코드 지원형 AI: 개발 과정에서 필요한 코드 아키텍쳐를 사용자 요청 및 개발환경에 맞춰 생성

  • 대표 서비스: Cursor, Claude Code

7. AI 모델 vs AI 서비스#

효과적인 AI 활용을 위해 모델과 서비스를 구분해서 이해하는 것이 중요하다.

  • AI 모델: 텍스트 생성, 이미지 생성, 추론 등 핵심 능력 자체
    • 예: GPT, Gemini Pro, Claude Opus, Veo, Sora, Kling
  • AI 서비스: 해당 모델을 사용할 수 있도록 제공되는 환경과 기능
    • 예: ChatGPT, Gemini, Claude.ai, Canva, Perplexity, Cursor

같은 모델이라도 어떤 서비스에서 제공되느냐에 따라 비용, 사용성, 연동 방식이 크게 달라진다. AI 활용 목적에 맞는 모델을 판단하고, 그 모델을 가장 효율적으로 제공하는 서비스를 선택하는 것이 핵심이다.

8. AI 활용 방법 3가지#

① AI 서비스에 접속해서 활용#

ChatGPT, Claude, Gemini 등 생성형 AI 서비스에 직접 접속하는 방법이다.

  • 별도의 설정이나 코드 작성 없이 로그인만 하면 바로 사용 가능
  • 접근성과 편의성이 높은 반면, 기능은 제공 서비스나 요금제에 따라 제한됨
  • LLM 모델은 개발사 서버에서 구동되므로 고사양 컴퓨터 불필요

② API로 활용#

OpenAI, Anthropic, Google 등에서 제공하는 API 키를 이용해 AI 모델을 활용하는 방법이다.

  • AI 모델에 대한 입력을 개발사 서버에 보내고 답변을 받아오는 방식
  • 프로그래밍이 익숙하다면 다양한 자동화나 나만의 AI 프로그램을 만들 수 있음
  • API 키의 사용량에 따라 비용이 청구됨

③ 모델을 로컬에 세팅하여 활용#

LLM 모델을 직접 다운받아 사용자의 컴퓨터(혹은 기업 서버)에 설치하고 활용하는 방식이다.

  • GPT, Gemini 등 대부분의 상용 모델은 전체 공개를 하지 않아 다운로드 불가
  • Meta의 Llama, DeepSeek, Google의 Gemma 등 무료(오픈소스)로 공개된 모델 이용 가능
  • 민감한 데이터 처리나 맞춤형 모델 튜닝이 가능하지만, 고성능 하드웨어(GPU)가 필요하고 기술적 부담이 있음

9. 텍스트 생성형 AI의 원리#

자기지도학습 (Self-supervised Learning)#

AI는 수많은 책, 뉴스 기사, 대화 텍스트 등을 학습하는데, 별도의 정답 라벨 없이 자주 나오는 단어들의 패턴을 기억하는 방식으로 스스로 학습한다.

예를 들어 “Second Law of Robotics: A robot must obey…” 라는 문장이 있을 때, AI는 앞의 단어들을 보고 다음에 올 단어(A → robot → must…)를 맞추는 예제를 스스로 만들어 학습한다.

자기 회귀 (Auto Regression)#

텍스트를 생성할 때는 학습한 단어들의 등장 확률을 바탕으로 가장 가능성이 높은 단어를 하나씩 선택해 문장을 만들어나간다. 단어 하나를 생성하고, 그 단어를 포함해 다시 다음 단어를 예측하는 과정을 반복한다.

10. 거대 언어 모델 (LLM)#

LLM(Large Language Model)은 방대한 텍스트 데이터를 학습한 대규모 언어 모델이다. ChatGPT, Claude, Gemini 등이 모두 LLM을 기반으로 한다.

LLM 추론 모델#

추론 모델은 정답을 바로 생성하는 것이 아니라, 중간 추론 과정을 거쳐 결과를 출력하는 언어 모델이다.

  • Chain of Thought(사고의 연쇄) 전략을 활용해 단계별 사고를 수행하여 기존 LLM보다 안정적인 성능을 보임
  • 특히 수학 문제 풀이, 논리 추론, 계획 수립 같이 단계적 사고가 필요한 고난도 작업에서 높은 정확도를 보임
  • 사고 과정을 거치기 때문에 긴 추론 시간과 토큰 소모량이 요구됨

11. 멀티모달 모델 (Multi Modal AI)#

사람이 여러 개의 감각기관을 활용하듯이, 비디오·이미지·소리·텍스트 등 다양한 형태의 데이터를 동시에 처리할 수 있는 모델이다.

  • 텍스트만 입력받던 기존 모델과 달리, 이미지를 보고 설명하거나 오디오를 듣고 답하는 등 복합적인 작업이 가능
  • 대표적인 멀티모달 서비스: OpenAI의 ChatGPT, Google의 Gemini

12. 이미지 생성형 AI의 원리#

확산 모델 (Diffusion Model)#

이미지 생성 AI의 핵심 원리다. 학습 방식은 두 단계로 나뉜다.

  1. Forward Diffusion (노이즈 추가): 원본 이미지에 수천 번에 걸쳐 점진적으로 노이즈(랜덤한 픽셀)를 추가해, 최종적으로 완전한 노이즈 이미지로 만든다.
  2. Reverse Denoising (노이즈 제거): AI가 노이즈를 단계적으로 제거하는 과정을 학습하면서, 결국 아무것도 없는 노이즈에서 이미지를 복원(생성)하는 능력을 갖추게 된다.

즉, 노이즈를 제거하는 방법을 학습함으로써 새로운 이미지를 만들어내는 것이다.

대표적인 이미지/영상 생성 모델#

Gemini 3 Pro Image (Nano Banana Pro): Google이 2025년 11월에 공개한 이미지 생성 모델로, Gemini 3 Pro의 추론 능력과 지식을 활용해 높은 수준의 시각화가 가능하다. 최대 14장의 입력 이미지 일관성 유지, 텍스트의 다국어 번역 및 렌더링 등의 기능을 지원한다.

Sora2: OpenAI가 공개한 영상 및 오디오 생성 모델로, 물리적 정확성·사실성·제어성을 크게 개선했으며 대사와 음향이 동기화된 영상 생성이 가능하다.

대표적인 오디오 생성 모델#

Fish Audio: 타인의 음성 샘플을 이용하여 사용자가 작성한 대사에 맞춰 음성(오디오)을 생성할 수 있는 생성형 AI 도구다.

13. AI Agent의 등장#

AI Agent란? = 자동화#

기본적인 생성형 AI가 프롬프트에 따라 콘텐츠를 생성하는 것에 그쳤다면, AI Agent는 한 걸음 더 나아가 목표를 이해하고, 스스로 계획을 세우며, 여러 도구를 활용해 작업을 수행하는 AI다.

구분 기본적인 생성형 AI AI Agent
역할 프롬프트에 따라 글·이미지 생성 요청에 맞춰 계획을 세우고 여러 작업을 수행
예시 블로그 글 작성 메일 발송 자동화, 툴 활용 작업 수행

에이전트의 4가지 특징#

특징 설명
목표 지향성 (Goal-Oriented) 사용자 지시나 환경 정보를 기반으로 최적의 결과를 도출하려고 함
자율성 (Autonomy) 인간의 모든 개입 없이도 문제 해결을 위해 스스로 판단하고 실행
상태 인식 (Perception) 입력 정보를 바탕으로 현재 상황(컨텍스트)을 파악
행동 수행 (Action) 툴 사용, 데이터 조회, 외부 API 호출 등 능동적인 작업 수행 가능

14. Physical AI의 등장#

Physical AI란?#

기존의 Software AI가 텍스트나 이미지를 다루는 디지털 세계에 머물렀다면, Physical AI는 실제 물리 환경에서 피지컬 로봇과 결합해 스스로 판단하고 움직이는 AI다.

  • 로봇, 스마트머신, IoT 장치 등과 결합해 실제 움직임, 조작, 제조 등을 수행
  • 단순 분석에 머물던 AI를 넘어, 현실 세계에서의 손발 역할을 수행

현실의 사례#

  • NVIDIA: OpenUSD로 로봇, 자율주행용 Physical AI 개발과 합성 데이터 생성 인프라 구축
  • Agility Robotics: Physical AI 기반 휴머노이드 로봇 Digit을 물류·제조 현장에 투입해 상용화 성공
  • Tesla (Optimus): 일론 머스크가 공개한 휴머노이드 로봇이 테슬라 공장에서 일부 단순 작업에 투입돼 실험 중

엔비디아의 젠슨 황은 에이전틱 AI 다음은 피지컬 AI이며, 이를 위해 옴니버스와 코스모스를 핵심으로 제시했다.

보충: Symbolic AI (기호적 AI)란?#

강의 자료에서 다룬 AI의 발전 흐름을 이해하려면, 머신러닝 이전에 존재하던 기호적 AI(Symbolic AI) 에 대한 이해가 필요하다.

개념#

기호적 AI는 사람이 직접 정의한 규칙(rules)과 논리(logic)를 기반으로 작동하는 AI다. 인간 전문가가 지식을 직접 정리해 지식 베이스(Knowledge Base)에 업로드하면, AI가 이를 추론 엔진(Inference Engine)으로 처리해 사용자의 질문에 답하는 방식이다.

동작 흐름#

전문가 → (지식 구축) → 지식 베이스 + 추론 엔진 → (답변) → 사용자

사용자가 질문을 입력하면, AI는 저장된 규칙과 논리 기호(∀, ∃, ∼ 등 술어 논리)를 조합해 답을 도출한다.

주요 특징#

  • 규칙 기반 시스템: AI의 행동이 인간이 작성한 규칙으로 완전히 결정됨
  • 명시적 지식: AI가 아는 것이 코드나 규칙으로 명확하게 기록되어 있음
  • 설명 가능성: AI가 왜 그런 답을 냈는지 추론 과정을 역추적해 설명할 수 있음
  • 기호 조작: 수학적 논리 기호(AND, OR, NOT, 전칭·존재 한정자 등)를 사용해 지식을 표현하고 조작함

한계#

전문가가 모든 규칙을 일일이 입력해야 하므로 지식 구축에 막대한 시간과 비용이 들고, 규칙으로 표현하기 어려운 복잡한 실세계 문제(예: 이미지 인식, 자연어 이해)에는 대응하기 어렵다. 이러한 한계를 극복하기 위해 등장한 것이 데이터로부터 스스로 패턴을 학습하는 머신러닝이다.
