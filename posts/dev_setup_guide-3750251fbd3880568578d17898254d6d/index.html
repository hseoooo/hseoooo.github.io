June 4, 2026

dev_setup_guide

개발환경 설정 실습 요약

1. GitHub 레포지토리 생성

  1. GitHub에서 New 클릭
  2. 레포지토리 이름 입력
  3. 옵션 설정:
    • Add README 체크
    • .gitignore: Python
    • License: MIT License

2. 로컬에 클론

같은 이름의 폴더가 이미 있으면 충돌 발생 — 미리 확인 또는 삭제

cd Desktop
git clone <GitHub_HTTPS_URL>   # 저장소 복제
cd <프로젝트_폴더명>             # 폴더 이동
code .                         # VS Code 실행 (공백 필수)

code .가 동작하지 않으면 VS Code에서 직접 Open Folder 사용

UV 환경설정 파일 (check_env.py, env.example, pyproject.toml)

3. UV 환경 설정 및 JupyterLab 실행

ls              # 파일 목록 확인
uv sync         # 패키지 설치
uv run python check_env.py   # 환경 점검 (파일명 Tab 자동완성 활용)
uv run jupyter lab            # JupyterLab 실행

터미널에 출력된 http://... 링크를 브라우저에 붙여넣어 접속.

환경이 꼬였을 경우: uv cache clean 후 재시도

실행 확인: JupyterLab에서 1 + 1 실행 → 결과 2 이면 정상

4. 변경사항 GitHub에 업로드

반드시 .git 폴더가 있는 프로젝트 디렉터리에서 실행

git add .               # 변경사항 스테이징 (add 와 . 사이 공백 필수)
git commit -m "update"  # 커밋 저장
git push                # GitHub에 업로드

업로드 후 GitHub 웹페이지 새로고침으로 결과 확인.

5. GitHub 인증 (최초 1회)

  1. Sign in with browser 선택
  2. 브라우저에서 GitHub 로그인
  3. Authorize 클릭 → 이후 push 자동 진행

같은 PC에서는 이후 반복 인증 불필요.
