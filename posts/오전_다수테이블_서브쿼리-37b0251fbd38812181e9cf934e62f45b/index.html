0610 SQL 다수 테이블 제어 및 서브쿼리

June 10, 2026

🗄️ 오전 수업 요약 | 다수의 테이블 제어 + 서브쿼리#

날짜: 2026-06-10

PART 1. 다수의 테이블 제어#

GROUP BY — 데이터 그룹 짓기#

여러 행을 특정 컬럼 기준으로 묶어 집계합니다. COUNT, SUM, AVG 등과 함께 사용합니다.

-- 국가별 고객 수 (많은 순)
SELECT Country, COUNT(*) AS customer_cnt
FROM customers
GROUP BY Country
ORDER BY customer_cnt DESC;

HAVING — 그룹에 조건 적용#

WHERE는 집계 전 개별 행을 필터링하고, HAVING은 집계 후 그룹을 필터링합니다.

-- 앨범이 5개 이상인 아티스트만
SELECT ArtistId, COUNT(*) AS album_cnt
FROM albums
GROUP BY ArtistId
HAVING COUNT(*) >= 5;

WHERE COUNT(*) >= 5 는 오류 — 집계 결과에는 반드시 HAVING 사용

INNER JOIN — 두 테이블 연결#

두 테이블에 모두 존재하는 행만 연결합니다. ON 절에 연결 조건을 씁니다.

-- 트랙 이름 + 장르 이름 함께 조회
-- 같은 컬럼명(Name)이 있을 때는 반드시 별칭(AS)으로 구분
SELECT tracks.Name AS track_name, genres.Name AS genre_name
FROM tracks
INNER JOIN genres ON tracks.GenreId = genres.GenreId;

INNER JOIN (3개 테이블) — 연쇄 연결#

JOIN은 두 테이블씩 순서대로 연결합니다.

-- 트랙 이름 + 앨범 제목 + 아티스트 이름
FROM tracks
INNER JOIN albums  ON tracks.AlbumId  = albums.AlbumId
INNER JOIN artists ON albums.ArtistId = artists.ArtistId;

LEFT JOIN — 왼쪽 기준 전체 출력#

왼쪽 테이블의 모든 행을 유지하고, 오른쪽에 매칭 데이터가 없으면 NULL로 채웁니다.

-- 앨범이 하나도 없는 아티스트 찾기
SELECT artists.Name
FROM artists
LEFT JOIN albums ON artists.ArtistId = albums.ArtistId
WHERE albums.AlbumId IS NULL;  -- 오른쪽이 NULL = 매칭 없음

RIGHT JOIN → LEFT JOIN으로 대체 (SQLite 호환)#

SQLite 구버전에서는 RIGHT JOIN을 지원하지 않습니다. 테이블 순서를 바꾸면 같은 결과를 얻을 수 있습니다.

-- RIGHT JOIN (최신 SQLite만)
SELECT artists.Name, albums.Title
FROM albums RIGHT JOIN artists ON albums.ArtistId = artists.ArtistId;

-- 동일 결과를 LEFT JOIN으로 (권장)
SELECT artists.Name, albums.Title
FROM albums LEFT JOIN artists ON artists.ArtistId = albums.ArtistId;

PART 2. 서브쿼리 기초#

서브쿼리란? SQL 문 안에 또 다른 SELECT를 넣는 것. 핵심 전략: 분할 → 각각 작성 → 합치기

단일 행 서브쿼리 — =, >, <#

서브쿼리가 값을 딱 하나 반환할 때 비교 연산자를 사용합니다.

-- 전체 트랙 평균 재생시간보다 긴 트랙
SELECT Name, Milliseconds
FROM tracks
WHERE Milliseconds > (SELECT AVG(Milliseconds) FROM tracks);
--                    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
--                    이 서브쿼리는 숫자 1개만 반환 → = > < 사용 가능

다중 행 서브쿼리 — IN / NOT IN#

서브쿼리가 여러 행을 반환할 때 IN을 사용합니다.

-- AC/DC 앨범에 속한 모든 트랙 이름
SELECT Name FROM tracks
WHERE AlbumId IN (
    SELECT AlbumId FROM albums
    WHERE ArtistId = (
        SELECT ArtistId FROM artists WHERE Name = 'AC/DC'
    )
);
-- 안쪽부터 읽기: ArtistId 1개 → AlbumId 여러 개(IN) → 트랙 이름들

ANY / ALL → SQLite에서는 MIN / MAX로 대체#

의미 다른 DB SQLite 대체
모든 값보다 크다 > ALL (...) > MAX(...)
하나라도보다 크다 > ANY (...) > MIN(...) 
-- Rock 장르의 모든 트랙보다 긴 트랙
SELECT Name, Milliseconds FROM tracks
WHERE Milliseconds > (
    SELECT MAX(Milliseconds) FROM tracks
    WHERE GenreId = (SELECT GenreId FROM genres WHERE Name = 'Rock')
);

스칼라 서브쿼리 — SELECT 절#

각 행마다 단일 값을 반환합니다. JOIN과 같은 결과를 낼 수 있습니다.

-- 앨범별 제목 + 트랙 수 (행마다 서브쿼리 실행)
SELECT Title,
       (SELECT COUNT(*) FROM tracks t WHERE t.AlbumId = a.AlbumId) AS track_cnt
FROM albums a;

FROM 절 서브쿼리 — 파생 테이블#

서브쿼리 결과를 임시 테이블처럼 사용합니다. 반드시 별칭(AS) 을 붙여야 합니다.

-- 국가별 매출 합계 TOP 5
SELECT BillingCountry
FROM (
    SELECT BillingCountry, SUM(Total) AS total_sales
    FROM invoices
    GROUP BY BillingCountry
    ORDER BY total_sales DESC
    LIMIT 5
) AS top5;  -- ← 별칭 필수!
