0608 SQL 기본쿼리문

June 8, 2026

SQL_기본쿼리문#

🗄️ 오후 수업 요약 | SQL 기본 쿼리문#

날짜: 2026-06-08

📖 DQL (Data Query Language) — 데이터 조회#

SELECT#

테이블에서 원하는 컬럼을 가져옵니다.

SELECT Title FROM albums;
SELECT * FROM tracks LIMIT 10;  -- 전체 컬럼, 10건만

DISTINCT#

중복된 값을 제거하고 고유한 값만 보여줍니다.

SELECT DISTINCT Country FROM customers;

WHERE + 비교 연산자#

조건에 맞는 행만 필터링합니다. (=, >, >=, <, <=, !=)

SELECT * FROM customers WHERE Country = 'USA';
SELECT * FROM tracks WHERE UnitPrice > 0.99 LIMIT 10;

AND / OR / NOT#

여러 조건을 조합합니다.

-- 둘 다 만족
SELECT * FROM customers WHERE Country = 'USA' AND State = 'CA';

-- 둘 중 하나 만족
SELECT * FROM customers WHERE Country = 'USA' OR Country = 'Canada';

-- 해당 조건 제외
SELECT * FROM customers WHERE NOT Country = 'USA';
SELECT * FROM customers WHERE Country != 'USA';

BETWEEN#

범위 조건. 양 끝값 포함.

SELECT * FROM invoices WHERE Total BETWEEN 5 AND 10;

IN / NOT IN#

여러 값 중 포함 여부를 확인합니다. OR를 간단하게 쓴 것.

SELECT * FROM customers WHERE Country IN ('USA', 'Canada', 'Brazil');
SELECT * FROM customers WHERE Country NOT IN ('USA', 'Canada', 'Brazil');

LIKE#

문자열 패턴 검색. %는 “0글자 이상 아무 문자”를 의미합니다.

SELECT * FROM albums WHERE Title LIKE 'Rock%';   -- 'Rock'으로 시작
SELECT * FROM albums WHERE Title LIKE '%Live';   -- 'Live'로 끝남
SELECT * FROM tracks WHERE Name LIKE '%Love%';   -- 중간에 'Love' 포함

ORDER BY#

결과를 정렬합니다. ASC(오름차순, 기본값) / DESC(내림차순).

SELECT Name, UnitPrice FROM tracks ORDER BY UnitPrice DESC;
SELECT Title FROM albums ORDER BY Title ASC LIMIT 10;

✏️ DML (Data Manipulation Language) — 데이터 조작#

INSERT#

테이블에 새 데이터를 추가합니다.

INSERT INTO book (id, title, category, price, rating, stock)
VALUES (13, 'It''s Only the Himalayas', 'Travel', 45.17, 2, 19);

-- 컬럼명 생략 시, 테이블 정의 순서대로 값이 들어감
INSERT INTO book VALUES (14, 'Set Me Free', 'Young Adult', 17.46, 5, 19);

UPDATE#

기존 데이터를 수정합니다.

UPDATE book SET price = 39.99 WHERE title = 'Soumission';

-- 기존 값을 기준으로 연산도 가능
UPDATE book SET stock = stock + 5 WHERE category = 'Poetry';

DELETE#

조건에 맞는 행을 삭제합니다.

DELETE FROM book WHERE rating = 1;
DELETE FROM book WHERE stock < 16;

⚠️ 중요 주의사항#

UPDATE / DELETE 에서 WHERE를 빠뜨리면 테이블 전체가 수정·삭제됩니다!

-- 절대 금지 (실수로 전체 삭제됨)
DELETE FROM book;
UPDATE book SET price = 0;
