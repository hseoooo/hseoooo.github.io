0604 Python 중급 문법 2

Python 심화 문법 요약

실무에서 자주 쓰는 6가지 심화 문법 패턴 개념 정리

1. f-string 포맷팅

Python 3.6+에서 사용 가능한 문자열 포맷팅 방법. 문자열 앞에 f를 붙이고, {중괄호} 안에 변수나 표현식을 직접 삽입한다.

name = "Alice"
score = 85

# 기본 변수 삽입
print(f"이름: {name}")

# 표현식 직접 사용
print(f"합격 여부: {'합격' if score >= 60 else '불합격'}")

숫자 포맷 지정자

형식 의미 예시
:.2f 소수점 n자리 f"{3.14159:.2f}" → 3.14
:, 천 단위 쉼표 f"{1000000:,}" → 1,000,000
:.1% 소수 → 퍼센트 (×100 후 % 붙임) f"{0.123:.1%}" → 12.3%
:.0f 소수점 없이 반올림 f"{6500/10000:.0f}만원" → 1만원

정렬 및 칸 채우기

# :<8  → 왼쪽 정렬, 8칸
# :>4  → 오른쪽 정렬, 4칸
print(f"{'팀명':<8} {'인원':>4}")
print(f"{'개발팀':<8} {3:>4}")
