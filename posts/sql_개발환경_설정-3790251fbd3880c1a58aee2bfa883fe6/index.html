0608 SQL 개발환경 설정

June 8, 2026

SQL_개발환경_설정#

📦 오전 수업 요약 | VS Code + SQLite 개발환경 설정#

날짜: 2026-06-08

🧠 핵심 개념: “왜 connect를 하는 건가요?”#

SQLite는 파일 하나가 곧 데이터베이스입니다.

mydb.db 같은 파일 안에 테이블, 데이터가 모두 저장됩니다.

VS Code는 코드 편집기일 뿐, 기본적으로 DB 파일을 읽거나 SQL을 실행할 수 없습니다.

그래서 SQLTools 확장을 설치하고, “이 .db 파일을 열어서 SQL을 실행하겠다”는 연결(Connection) 을 만들어야 합니다.

내 컴퓨터 안에서 일어나는 일:
  [VS Code] ──(SQLTools 확장)──▶ [mydb.db 파일] ──▶ 쿼리 실행 & 결과 출력

연결을 설정한다 = “VS Code야, 이 경로에 있는 .db 파일을 SQLite DB로 인식하고 쿼리 받아줘” 라고 알려주는 것.

✅ 오늘의 목표 (1차 관문)#

  • VS Code에서 제공 코드 실행 시 결과값 정상 출력
  • SQLite 연결 테스트에서 “Successfully connected” 메시지 확인

🔧 설치 및 설정 순서#

1단계 | VS Code 확장(Extension) 설치#

Ctrl + Shift + X → 아래 3개 검색 후 설치

확장명 역할
SQLTools SQL 실행 및 커넥션 관리
SQLTools SQLite SQLTools의 SQLite 드라이버
SQLite Viewer .db 파일을 시각적으로 확인

2단계 | Node.js 설치 (Windows만)#

일부 PC에서 SQLTools 활성화 오류 방지용.

  1. Node.js 공식 사이트에서 설치
  2. 설치 중 Add to PATH 체크 ✅
  3. 설치 후 재부팅
  4. VS Code 터미널에서 확인:
node -v
npm -v
# 버전 숫자가 출력되면 성공

3단계 | 작업 폴더 및 DB 파일 생성#

C:\test_gongyu_0608\       ← VS Code에서 Open Folder로 열기
    └── mydb.db            ← 새 파일 생성 (내용 비어도 됨)

터미널에서 pwd 입력 → 현재 경로 확인 (커넥션 설정 시 필요)

4단계 | SQLTools 커넥션 생성#

  1. 좌측 SQLTools 패널 → Add New Connection
  2. 타입: SQLite 선택
  3. Connection Name: 원하는 이름 (예: mydb.db)
  4. Database File 경로 입력 (/Users/()/Desktop/yeardreamschool6th/mydb.db)
    • Windows: 역슬래시 \\ 사용 주의
    • Mac: 슬래시 / 사용
  5. Test Connection → "Successfully connected" 확인
  6. Save → Connect Now

5단계 | 단축키 설정#

Ctrl + K → Ctrl + S (Mac: Cmd + K → Cmd + S)

→ 검색: SQLTools

→ Run Selected Query 단축키를 Ctrl + Enter 로 변경

6단계 | 레이아웃 설정#

View → Editor Layout → Two Rows

→ SQL 쿼리(위) + 결과창(아래) 배치로 실습 편의성 향상

⚠️ 자주 발생하는 오류#

증상 해결 방법
“파일이 없다” / 경로 요구 .db 파일명 오타, 슬래시 방향 확인
“Install / Enable / Reload” 메시지 순서대로 클릭: Install Now → Enable → Reload Now
확장이 활성화 안 됨 (Windows) Node.js 설치 후 재부팅

📌 오늘의 미션#

datasense/
    └── something.db       ← 임의의 DB 파일 생성
